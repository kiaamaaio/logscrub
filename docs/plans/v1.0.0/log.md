### v1 完了後のレビューによる修正(2026-10-11、利用者が方針を確認済み)

- `-o` の出力先が、標準入力のリダイレクト元(`mask -o app.log < app.log`)と同じファイルの場合も、エラーにする。
  従来は、入力の `-` を比較から外していたため、入力が空になっていた(仕様 6 章の「入力を消さないため」の趣旨)
- キー名ベースの引用符なしの値で、`token=token=…` のような行が、1 行の長さの 2 乗の時間になっていた
  (240KB の行で約 2.8 秒)。直前に求めた値の範囲の中から始まる値は、同じ終端を使い回す(結果は変わらない。正規表現の別実装との乱数テストで確認)
- Slack の接頭辞から、仕様にない `xoxo-` を外した(仕様 4.1 の `xoxb-` `xoxp-` `xoxa-` `xoxr-` `xoxs-` のみ)
- `logscrub types` に引数を渡すと、エラー(終了コード 1)にする
